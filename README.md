# Sezer Invest — Next.js demo

sezerinvest.com.tr (WordPress) ana sayfasının özel yazılıma taşınmış hali.

- Next.js 16 (App Router) + Tailwind CSS 4
- İlan verisi: `src/data/listings.json`, site metinleri: `src/data/site.ts`
- Döviz şeridi: TCMB günlük kurları (saatlik yenilenir)

```bash
npm install
npm run dev
```
